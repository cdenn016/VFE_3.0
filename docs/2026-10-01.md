## Predictive covariance centering toggle

Added `predictive_covariance_centering`, defaulting to `False`, to `VFE3Config` and the `train_vfe3.py` and `ablation.py` configuration dictionaries. `False` selects the historical raw-source covariance spread; `True` enables the newer first-source centering before content projection. Every relational layer receives the setting. The field serializes with the configuration, uses strict boolean validation, and is reported inactive outside moment-matched predictive covariance. Missing fields in older serialized configurations select the historical calculation.

The new tests select an explicit tiny predictive configuration independently of launcher defaults and the concurrent test-isolation work. They cover layer wiring and forwards, serialization, missing-field behavior, the numerical effect of a shared mean offset, finite-difference gradients through normalized routing for both settings, boolean validation, and inactive-field reporting. The pre-implementation test failed on the missing configuration field.
