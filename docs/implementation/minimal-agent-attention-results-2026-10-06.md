## The readout

A new predictive readout of `attention_mode="projected_predictive"`, selected by `predictive_readout="minimal_agent"`, replaces the predictive-kernel content by exact Gaussian conditioning of every receiver on a noisy comparison record. Token `i` carries the reference moments `xi_i = U_i^{-1} mu_i` and `C_i = U_i^{-1} Sigma_i U_i^{-T}`. Head `h` (width `d`, `K = H d`) has the query map `S_h` (the existing `raw_score_q[h]`), the sending map `T_h` (the existing `T[h]`), which is also the key (tied key and content), and the isotropic channel noise `N_h = n_h I_d` with `n_h = exp(channel_log_noise[h])`. The receiver's state `X_i ~ N(xi_i, C_i)` is conditioned on `o_h = S_h X_i - T_h X_J + eps_h = 0`; the label `J` has the routing log-prior (causal mask, ALiBi or any registered prior) as its prior, every source is an independent snapshot of its input belief (the self edge included), and each head hears its own snapshot.

For one head, with `a_i = S xi_i`, `A_i = S C_i S^T`, `b_j = T xi_j`, `B_j = T C_j T^T + n I` and `W_ij = A_i + B_j`, the implementation computes the exact posterior of Proposition `ma:prop:minimal` (a): `w_ij = softmax_j(log pi_ij - c_ij)` with `c_ij = (b_j - a_i)^T W_ij^{-1} (b_j - a_i)/2 + log det W_ij / 2` (temperature 1, no clamp), `r_ij = W_ij^{-1}(b_j - a_i)`, `u_i = sum_j w_ij r_ij`, `Lambda_bar_i = sum_j w_ij W_ij^{-1}`, `R_i = sum_j w_ij r_ij r_ij^T - u_i u_i^T`, and with the gain basis `Kmat_i = C_i S^T` the update `xi_i^+ = xi_i + Kmat_i u_i`, `C_i^+ = C_i - Kmat_i (Lambda_bar_i - R_i) Kmat_i^T`. These are the moments of the mixture `sum_j w_ij N(m_ij, P_ij)` with `m_ij - xi_i = Kmat_i r_ij` and `P_ij = C_i - Kmat_i W_ij^{-1} Kmat_i^T`, so `C_i^+` is a mixture covariance (positive definite because every `P_ij^{-1} = C_i^{-1} + S^T B_j^{-1} S` is). No residual is added: the residual is the precision-weighted part `(I - G S) xi_i` of the gain update.

Several heads (`minimal_agent_inference="exact"`) are conditioned in index order by assumed-density filtering: head `h` applies the one-head posterior to the Gaussian left by heads `1..h-1` (sources stay their input snapshots) and collapses to two moments, `xi^(h) = xi^(h-1) + Kmat^h u^h`, `C^(h) = C^(h-1) - Kmat^h M^h Kmat^hT`, `M^h = Lambda_bar^h - R^h`. `C^(h-1)` is never formed: with `Y_hg = S_h Kmat^g`, `Kmat^h = C S_h^T - sum_{g<h} Kmat^g M^g Y_hg^T` and `A^h = S_h C S_h^T - sum_{g<h} Y_hg M^g Y_hg^T`, so only `K x d` and `d x d` matrices appear and block-diagonal inputs stay blockwise. The module docstring proves that ADF equals Proposition `ma:prop:minimal` (b) in the per-head snapshot model whenever `S_h C_i S_g^T = 0` for `h != g` (by induction `S_h C^(g) = S_h C`, so every head sees the input moments and the label posterior factors); otherwise ADF is a declared, order-dependent approximation in which every step is an exact mixture moment match.

The mean-field variant (`minimal_agent_inference="mean_field"`, Proposition `ma:prop:mean_field`) takes every head's labels at the INPUT receiver moments, `beta_ij^h = softmax_j(log pi_ij^h - KL(N(a_i^h, A_i^h) || N(b_j^h, B_j^h)))`, through `vfe3.relational_scoring.projected_gaussian_kl` with the noisy key covariance `B_j^h`, and fuses the power posterior in information form, `P_i^{-1} = C_i^{-1} + sum_h S_h^T Lambda_i^h S_h`, `xi_i^+ = P_i (C_i^{-1} xi_i + sum_h S_h^T eta_i^h)`, `C_i^+ = P_i`, with `Lambda_i^h = sum_j beta_ij^h B_j^{-1}` and `eta_i^h = sum_j beta_ij^h B_j^{-1} b_j^h`. The fusion runs through the same sequential assembly: head `h` is the Gaussian pseudo-observation `y^h = Lambda^{-1} eta` of `S_h X_i` with covariance `Lambda^{-1}`, whose Kalman step `M = (A + Lambda^{-1})^{-1} = L E^{-1} L^T`, `u = L E^{-1}(L^{-1} eta - L^T a)` (`Lambda = L L^T`, `E = I + L^T A L`, eigenvalues at least 1) adds exactly `S_h^T Lambda S_h` to the precision and `S_h^T eta` to the information vector, so the sequential result equals the information form exactly, in any head order. The mean-field covariance omits the between-source spread.

## Module and functions

The math lives in the new module `vfe3/model/minimal_agent.py` as pure functions with LaTeX docstrings and shape comments. `exact_record_posterior(a, A, b, B, log_prior=None, *, check=True) -> RecordPosterior(weights, cost, u, Lambda_bar, R, failed)` takes `a (..., I, r)`, `A (..., I, r, r)`, `b (..., J, r)`, `B (..., J, r, r)` and a log-prior broadcastable to `(..., I, J)`. It needs one `r x r` Cholesky factor per pair and makes ONE pass over bounded pair tiles with an online log-sum-exp over the source tiles: each tile (`_exact_tile`) returns its costs and its statistics `sum_j exp(l_ij - t_i)(1, r_ij, W_ij^{-1}, r_ij r_ij^T)` at its own detached row maximum `t_i`, and the caller combines tiles outside any checkpoint with detached scales. Tiles hold about `PAIR_TILE_BYTES = 32 MiB` of `W_ij`, its factor and `W_ij^{-1}` (row tile at most 32), each tile is a non-reentrant checkpoint when gradients are on and the grid has more than one tile, autocast is disabled, the compute dtype is `_compute_dtype` of the inputs, factorizations use zero jitter and no repair, and `check=True` makes one host check and raises `ValueError`. Masked pairs get weight exactly 0; their `W_ij` is still positive definite and never produces a non-finite value. `mean_field_record_posterior(a, A, b, B, log_prior=None, *, check=True) -> MeanFieldPosterior(weights, cost, Lambda, eta, failed)`, `label_statistics(weights, b, B) -> (Lambda, eta, failed)` and `information_step(a, A, Lambda, eta) -> (u, M, failed)` implement the mean field. `gain_basis(C, S, blocks) -> (..., N, H, K, d)` forms `C_i S_h^T` for dense `(..., N, K, K)` or block `(..., N, G, g, g)` covariances, `sequential_head_assembly(xi, X0, S, head_update) -> (xi_plus, gains, M, A)` is the shared ADF loop (`head_update(h, a, A) -> (u, M)`), `minimal_agent_readout(xi, C, S, T, log_noise, log_prior=None, inference="exact", *, diagnostics=False, check=True) -> MinimalAgentResult(xi, gains, M, weights, cost, gain_fraction, query_covariance, key_covariance, head_coupling, failed, ill_conditioned)` assembles a layer (a `C` with two more axes than `xi` is read as block-diagonal blocks; `gain_fraction` and `head_coupling` are None unless `diagnostics=True`; `check=False` returns the failure flag and the float32 certificate flag instead of making the host check, and `readout_failure_message(dtype)` is the error text), and `local_posterior_covariance(sigma, forward, block_diagonal, gains, M, floor_scale)` returns `Sigma_i^+ = Sigma_i - sum_h Z_i^h M_i^h Z_i^hT + f (tr C_i / K) U_i U_i^T` with `Z_i^h = U_i Kmat_i^h`, or for a diagonal input its diagonal `diag Sigma_i - sum_h rowquad(Z_i^h, M_i^h) + f (tr C_i / K) diag(U_i U_i^T)`, which never forms a `K x K` matrix (`Sigma_i = U_i C_i U_i^T` exactly, so the input covariance is reused). Constants: `PREDICTIVE_READOUTS`, `MINIMAL_AGENT_INFERENCE`, `PAIR_TILE_BYTES`, `MINIMAL_AGENT_DIAGNOSTIC_KEYS`.

## Wiring

`RelationalOperators` (`vfe3/model/relational_operators.py`) takes `predictive_readout`, `minimal_agent_inference` and `minimal_agent_channel_noise`, validates them, and under `"minimal_agent"` refuses the full-link readout, mixed heads, edge links and `attention_residual=True`. It then stores `raw_score_q` initialized EQUAL to `T`'s block projector (the record compares like coordinates at step 0, so the initial routing is the overlap of the same observable of receiver and source and the derived gain writes the heard utterance back into the coordinates it was read from), `T` with its block-projector initialization, and `channel_log_noise` of shape `(H,)` at `log(minimal_agent_channel_noise)`; `raw_score_k` and `O` are registered as `None`, so they are absent from the state dict and from `parameters()`. A kernel operator has no `channel_log_noise` attribute and no new parameter or buffer. `comparison_runs()` and `comparison_pair()` return `(S_Q, T)` under the minimal agent, `inference_semantics` is `relational_minimal_agent_exact` or `relational_minimal_agent_mean_field`, and every O-reading method (`content_factors`, `content_factor_runs`, `predictive_content`, `predictive_covariance_update`, `edge_context`, `_ambient_content_runs` and through it `_ambient_content_maps`, `_receive_runs`, `_content_parameters`) raises a `ValueError` naming the mode. `minimal_agent_update(mu, sigma, frame, log_prior=None, *, return_covariance=False, capture=None) -> (mu_plus, sigma_plus or None)` forms `xi` and `C` (diagonal blocks for diagonal beliefs on block frames, else dense), calls `minimal_agent_readout`, maps back `mu^+ = U xi^+` and, with `return_covariance`, the floored posterior covariance in the input layout. Under `predictive_covariance_checkpoint=True` (and gradients on) the whole body is one non-reentrant checkpoint (no random numbers), and the capture is written outside it, from the body's returned record. The body also returns the readout's status `(failed, ill_conditioned)` unchecked, and `minimal_agent_update` makes the one host check of the call: a float32 call that reports either flag is recomputed whole in float64 (section "Review remediation"), and a float64 failure raises `ValueError`.

`relational_predictive_readout` (`vfe3/gradients/relational.py`) dispatches on `operators.predictive_readout`: under the minimal agent it skips `relational_score`, `attention_weights` and `predictive_content`, reads the ROUTING frame for query, key, content and write-back, refuses a distinct `value_frame` object whose matrices differ, ignores `tau` and `kl_max`, and returns the posterior mean (and covariance when asked). The E-step is unchanged: it requests the covariance only under `moment_matched` and otherwise keeps the incoming covariance. `VFEModel` passes the three settings to every layer and passes `attention_residual=False` to minimal-agent operators. `build_optimizer` adds `channel_log_noise` to the relational SCORE group (`m_relational_score_lr`, weight decay 0, aux role `relational_score`; the coverage guard stays green), and `_parameter_group` and `run_resources.parameter_role` classify it as `relational_score`, so resource accounting counts score `H d K + H` and content `H d K` per layer.

## Diagnostics

With a capture, `minimal_agent_update` records `beta_pre` (the labels each head used, `(..., H, N, N)`), `score_energy_pre` (their per-pair costs: the record costs `c_ij` at each head's ADF moments, or the KL costs at the input), `projected_covariance_pre` (`S_h C_i S_h^T` at the input), `projected_key_covariance_pre` (`T_h C_j T_h^T`, the noise-free key law), `relational_mean_displacement_norm`, and per head `(H,)` the three keys of `MINIMAL_AGENT_DIAGNOSTIC_KEYS`: `relational_minimal_agent_gain_fraction` (receiver mean of `tr(A^h Lambda_bar^h)/d` at head `h`'s ADF moments for the exact path, which depends on the head order as ADF does, and of `tr(A_0^h M_0^h)/d = 1 - tr(E^{-1})/d` at the INPUT moments for the mean field, `A_0^h = S_h C_i S_h^T`, `M_0^h = (A_0^h + Lambda^{h,-1})^{-1}`, `E = I + L^T A_0^h L`, `Lambda^h = L L^T`, which does not depend on the head order, as the fused posterior does not; both in `[0, 1)` and computed only when a capture is requested), `relational_minimal_agent_channel_noise` (`n_h`) and `relational_minimal_agent_head_coupling` (receiver mean of `max_{g != h} ||S_h C_i S_g^T||_F / (||S_h C_i S_h^T||_F ||S_g C_i S_g^T||_F)^{1/2}` at the input moments; 0 means ADF is exact, and a single head reports 0). The per-layer diagnostics row reports the head mean of the first two and the head maximum of the coupling, and the training loop appends `val_relational_minimal_agent_gain_fraction`, `val_relational_minimal_agent_channel_noise` and `val_relational_minimal_agent_head_coupling` (`train._VAL_MINIMAL_AGENT_DIAG_KEYS`) to the metrics schema of minimal-agent runs only, like the edge-link columns. At initialization `S_Q = T` is the block projector, so on block frames the coupling is exactly 0 whenever `C_i` is block diagonal: always for diagonal beliefs, and for the full family while `Sigma_i` is block diagonal (the moment-matched update keeps `C_i` block diagonal while the coupling is 0). A tiny two-layer `block_glk` model (two heads of width 2, both families, both modes) reported 0.0 in both layers at initialization.

## Review remediation

The review of this implementation reported one major finding and five minor ones. This section records what was changed, what was measured and what was left unchanged, with reasons.

Float32 failures of the ADF query covariance (major). In float32 the query covariance of a later head, `A^h = S_h C S_h^T - sum_{g<h} Y_hg M^g Y_hg^T`, is a downdate. Its rounding error grows with `||S_h C S_h^T||` and with the float32 error of the earlier heads' inverses `W_ij^{-1}` (about `cond(W_ij) eps`). With coupled heads and an ill-conditioned `C_i` the downdate can cancel the smallest eigenvalues of `A^h`, and the call raised although the exact `A^h` is positive definite. The review's instance (K = 32, H = 4, d = 8, N = 32, frames and maps `I + 0.3 randn`, diagonal variances in (0.3, 1.3), channel noise 1, maximum head coupling 0.91, maximum `cond C_i` 8.7e6) was reproduced: in float32 the second head's `A^h` had a minimum eigenvalue of -247, against 0.745 in float64, and 64 of 1024 pair factorizations failed. The remediation keeps zero jitter, never repairs a covariance, and adds three things. First, `minimal_agent_readout` factors every `A^h` (zero-jitter Cholesky of the `(d, d)` matrices, no extra host transfer) and folds its failure flag into the call's flags, so that the error of a failed call names the ADF query covariance and, in float32, the cancellation. Second, under `projected_cov_condition_recovery` a float32 call also screens every `A^h` with the certificate `eps ||S_h C_i S_h^T||_F ||(A_i^h)^{-1}||_F > projected_gram_condition_tol`. For the first head this is the kernel's Gram-route certificate of the projected query covariance. It is a screen and does not bound the error contributed by the earlier inverses. Third, `RelationalOperators.minimal_agent_update` makes the call's one host check. A float32 call that reports a failure or a certificate flag is recomputed whole in float64 from the local beliefs, frame and prior, and its outputs and capture are cast back to the input dtypes. A float64 failure raises `ValueError`, and so does a failure of the float64 recomputation.

The whole call is recomputed, not only the flagged receivers. A failed factorization in a pair tile that also holds healthy receivers can put NaN into the gradients of the shared sources and parameters during backward, even with zero cotangent, so splicing in the healthy receivers of the float32 attempt is not safe; the float32 attempt is discarded instead. The recomputation counts every query and key entry of the call (`2 B N H`) in the source-recovery counter that the training loop reads, so `factorization_fallback_count / factorization_count` is the share of recomputed layer calls. For the mean field under the certificate, the entries that `projected_gaussian_kl` already refactored in the discarded attempt are subtracted, so no entry is counted twice. The mean field's `projected_gaussian_kl` factors the input query and utterance covariances itself and raises on a failure, so the readout factors them first and passes an identity placeholder for a failed entry; a healthy call is unchanged bit for bit. The `A^h` check also applies in float64, where an indefinite `A^h` now raises; no float64 test case comes near this. The run record's `factorization_fallback` strings changed accordingly (section "Consumer audit").

Measured float32 operating range (CPU, one thread). On the review's instance the float32 call is now recomputed in float64 in both modes. The result lies within 3.4e-6 (mean) and 1.3e-6 (covariance) of the float64 readout of the unrounded inputs for the exact path, and within 7.9e-6 and 1.3e-6 for the mean field; the gap comes from rounding the inputs to float32. The result and every gradient equal, bit for bit, the float64 readout of the float32-rounded inputs and parameters, cast back. The review's controlled grid has 48 cases: K = 32, N = 32, maps `I + 0.1 randn`, frames of exact condition 1, 10 and 100, diagonal variances log-uniform over a factor of 1, 1e2, 1e4 and 1e6, channel noise 1 and 1e-2, both modes. Its maximum `cond C_i` reaches 1.3e9 and its maximum coupling ranges from 0.34 to 0.71. With the certificate off, no case fails in float32 and none is recomputed. Against float64, the largest relative errors are 1.3e-4 (mean) and 1.0e-4 (covariance) for the exact path and 3.5e-4 and 2.1e-4 for the mean field, with no nonpositive variance. With the certificate on, 30 of the 48 cases are recomputed, with errors of at most 3.4e-6. In these runs the certificate trips once the maximum `cond C_i` reaches about 7.8e3 at noise 1e-2, or 6.9e5 at noise 1 with well-conditioned frames. So with the certificate off, float32 is accurate to about 1e-4 relative wherever it does not fail. The failure that remains needs strongly coupled heads together with an ill-conditioned `C_i`, and that case is now recomputed instead of raised. This is a K = 32 grounding; it says nothing quantitative about K = 128 or about trained frames.

Costs of the remediation. On the healthy path the added work is one zero-jitter factorization of `A^h` per receiver and head, plus, for the mean field, one each of the input query and utterance covariances. These operations were timed alone against the readout forward at K = 128, H = 4, d = 32, batch 1, float32, one CPU thread, diagonal beliefs on block frames. They cost 0.5 to 1.0 percent of the exact readout (0.36 ms of 37 ms at N = 32, 0.73 ms of 133 ms at N = 64) and 6.4 to 6.5 percent of the mean field (1.05 ms of 16 ms, 2.06 ms of 32 ms), because `projected_gaussian_kl` factors the same two covariances again. A recomputed call costs the float32 attempt plus the float64 call. At N = 64 the float64 call took 183 ms against 136 ms in float32 (exact) and 49 ms against 33 ms (mean field) on this CPU, so a recomputed call costs about 2.4 and 2.5 times a healthy one. On the RTX 5090, whose float64 throughput is a small fraction of its float32 throughput, the factor will be larger; it was not measured. Under `projected_cov_condition_recovery`, a run whose layers trip the certificate on most calls pays that factor on most calls.

Minor findings. The mean field's gain fraction is now evaluated at the input moments (section "Diagnostics"), so it no longer depends on the head order. A new test checks both heads against `tr(A_0 M_0)/d` computed from the labels. It also checks that reversing the heads permutes the fractions and leaves the fused posterior unchanged, while the exact path's fraction moves, since it reads the ADF moments. The gain fractions of both paths are now computed only when diagnostics are requested, like the head coupling (plan Section 2.5), which removes their per-call cost from training steps. `checkpoint_holonomy` refuses a minimal-agent checkpoint before its validation pass. The finite-difference test differentiates the finite entries of the log prior. The diagnostics are still reported per layer as head means (gain fraction, channel noise) and the head maximum (coupling), with the per-head values in the capture, which the review allowed. Persisting them would need a per-(layer, head) artifact like `cap_activation.csv`, which nothing asked for. Fully masked pair tiles are still factored and inverted (section "Not done").

## Deviations from the plan, with reasons

The mean-field gain fraction is `tr(A_0^h M_0^h)/d` with `M_0^h = (A_0^h + Lambda^{h,-1})^{-1}` at the input moments `A_0^h = S_h C_i S_h^T`, not `tr(A Lambda)/d`. The latter is a signal-to-noise ratio, unbounded above, and it does not reduce to the exact gain fraction where the two models agree; `tr(A M)/d` is the whitened share of the probed variance that the head's channel information removes, lies in `[0, 1)`, and equals `tr(A Lambda_bar)/d` for one head with equal `B_j` and `beta = w`. The implementation first evaluated it at the sequential moments of the fusion, which made the reported value depend on the head order although the fused posterior does not; the review remediation moved it to the input moments.

In float32 a call whose factorizations fail, or, under `projected_cov_condition_recovery`, whose ADF query covariance fails the certificate, is recomputed whole in float64 instead of raising (plan Section 2.3 says one host check that raises). No covariance is repaired, the failure still raises in float64, and the reason is that the ADF downdate of `A^h` can lose positive definiteness in float32 by cancellation on inputs that the exact model handles (section "Review remediation").

The gain fraction (both paths) and the head coupling are computed only when diagnostics are requested; without a capture `MinimalAgentResult.gain_fraction` is None.

The exact per-pair cost is `-log N(b_j; a_i, W_ij) - (r/2) log 2 pi`, without the row constant `-log det A_i / 2` of `projected_noisy_query_cost`. The softmax is unchanged and the test checks the relation to the noisy-query cost. The cost needs no factor of the ADF query covariance; since the review remediation the readout factors every `A^h` anyway, as a positive-definiteness check (section "Review remediation").

The mean-field fusion runs as an exact sequential Kalman update in the shared assembly instead of inverting a dense `K x K` precision. It is equal in exact arithmetic (proved in the docstring, tested to 1e-10) and keeps block-diagonal inputs blockwise.

`return_covariance=True` on `minimal_agent_update` and on the readout returns the floored posterior covariance whatever `predictive_covariance` says; `"passthrough"` is applied by the E-step, which neither requests nor writes a covariance. This is the existing contract of the kernel readout.

The tile-boundary test compares one-pair tiles with the default tile at `rtol 1e-11`, not bitwise: the online log-sum-exp sums in a different order. The `predictive_covariance_checkpoint` comparison is bitwise.

The pure functions return their failure flag and take `check`, so the readout folds every head's flags into one host check per layer, which `minimal_agent_update` makes (the readout called alone makes it itself with `check=True`); the mean field's `projected_gaussian_kl` keeps its own host transfer.

`projected_factor_route` is also marked inactive under the minimal agent, which passes no source tuples to any factorization, and `predictive_covariance_checkpoint` stays active under passthrough for the minimal agent.

The operator refuses `attention_residual=True` under the minimal agent and the model passes False, while the config accepts any value and marks it inactive; otherwise the posthoc residual row would have toggled a flag the readout ignores.

`raw_score_k` and `O` are registered as `None` parameters rather than left undefined, so the existing `getattr(ops, name) is not None` checks keep working; they have no state-dict keys.

The diagnostics are kept per head in the capture, and the per-layer row reports head means and the head maximum of the coupling, because the metrics schema is scalar.

## Not done

GPU cost was not measured, no training-scale or large-N run was made, and the full test suite was not run (the integration stage runs it). At this stage the exact path factored and inverted every pair tile, the fully masked ones of a causal prior included (at the launcher tile shape, 32 receivers by 2 sources, 96 of 256 tiles per head and layer are fully masked), because the reference test `test_one_pair_tiles_reproduce_the_single_tile_values_and_gradients` asserted that every tile runs through `_exact_tile` once in the forward pass and once in the backward recomputation. At the user's decision the follow-up in `docs/2026-10-06.md` skips them entirely: a grid of more than one tile makes one host read of the tile mask, a tile the prior masks in every batch element is neither factored nor checkpointed, and its entries of `cost` read 0 (finite; the weights there are exactly 0 either way). The weights, `u`, `Lambda_bar`, `R` and the gradients are unchanged, since a masked pair contributes exact zeros; the costs agree on the prior's support, and masked pairs inside a diagonal tile keep their computed cost. The reference assertion now counts the tiles that hold an unmasked pair. Mixed `so_n` towers, edge links, `pos_rotation="rope"` with `rope_on_value=False` and the `projected_gradient` receiver are refused for the minimal agent rather than supported. The triangle-holonomy analysis and the routing decomposition refuse it, interventions 2, 3, 4, 6 and 10 report `NotApplicable`, and interventions 9, 11 and 12 were not run on a minimal-agent model. The training counters `factorization_fallback_count / factorization_count` measure the share of float32 layer calls recomputed in float64 (section "Review remediation"); the certificate on the ADF query covariances is a screen with the tolerance of the kernel's Gram certificate, not an error bound, and the cost of a recomputed call on the GPU was not measured. The relayed comparison of the baseline run (55 test perplexity) with the K = 128 run was not analyzed, and no run artifacts were read for it. The launchers `train_vfe3.py` and `ablation.py` carry the three new fields at their defaults (follow-up); the minimal agent is selected by setting `predictive_readout`. The size of the ADF error with coupled heads at large K and H is unknown: the two-head, K = 5 instance above grounds the implementation and says nothing about that scale, and the coupling diagnostic reports how far each layer is from the exact case. `docs/2026-10-06.md` was not edited (the integration agent writes that entry).
